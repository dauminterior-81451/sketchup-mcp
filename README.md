# SketchUp MCP

SketchUp 2023 English desktop version helper.

## Structure

```text
mcp-server/server.js
sketchup-plugin/daum_mcp_bridge.rb
docs/INSTALL.md
```

## Available MCP tools

- `sketchup_ping`
- `sketchup_status`
- `sketchup_model_summary`
- `sketchup_selection`
- `sketchup_rename_selection`

## Default bridge URL

```text
http://127.0.0.1:8765
```
